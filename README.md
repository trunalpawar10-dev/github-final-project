# Simple Interest Calculator

## Project Name

**Simple Interest Calculator** – A Bash-based command-line tool to compute simple interest given a principal amount, rate of interest, and time period.

## Description

This project provides a simple Bash script (`simple-interest.sh`) that allows users to calculate **Simple Interest** quickly from the terminal. It was developed as part of a micro-finance startup initiative to provide open-source financial tools.

## Features

- Interactive user prompts for input
- Computes Simple Interest using the formula: **SI = (P × R × T) / 100**
- Lightweight and dependency-free (pure Bash)
- Cross-platform Unix/Linux/macOS compatible

## Getting Started

### Prerequisites

- Bash shell (v4+)
- Unix/Linux or macOS terminal

### Usage

```bash
# Clone the repository
git clone https://github.com/trunalpawar10-dev/github-final-project.git

# Navigate into the project directory
cd github-final-project

# Make the script executable
chmod +x simple-interest.sh

# Run the script
./simple-interest.sh
```

### Example

```
Enter the principal amount: 1000
Enter the rate of interest (% per year): 5
Enter the time period (in years): 3

Simple Interest = 150.00
```

## Formula

```
Simple Interest (SI) = (Principal × Rate × Time) / 100
```
